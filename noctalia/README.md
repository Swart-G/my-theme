# Niri + Noctalia

Второе оформление репозитория: текущая композиция Niri, Noctalia 5 и родного
Noctalia Greeter. Первый установщик `install.sh` устанавливает Rodip Glass
для Plasma. Их резервные копии и настройки разделены.

## Установка

Из скачанного репозитория, обычным пользователем, без `sudo`:

```bash
bash ./install-noctalia.sh
```

Полная автоматическая установка рассчитана на Fedora 44 с systemd. Нужны
Python 3.11+ и сеть. Пакеты и экран входа требуют системной авторизации.
Устанавливаются Niri, Noctalia, Alacritty, fish, VLC, Loupe, Dolphin, шрифты Adwaita Sans/Hack,
значки и курсоры Breeze, средства управления звуком/яркостью и Wayland-портал.
Для приложений GTK включена текущая тема Lavanda-Sea и шрифт Noto Sans.

Noctalia Greeter берётся из [Terra](https://terrapkg.com) —
[указанного проектом источника Fedora](https://github.com/noctalia-dev/noctalia-greeter/blob/main/docs/user/installation.md).
Создаётся `/etc/yum.repos.d/rodip-noctalia.repo`, ограниченный пакетом
`noctalia-greeter`. Остальные зависимости берутся из Fedora/updates.
Проверка подписей включена. Публичный ключ Terra 44 включён в комплект;
отпечаток: `AE09157A4DE88B497EA1D5D300CDAB43DE226D6F`.

Установщик сохраняет пакетный PAM Fedora и установленные сеансы. В greetd
меняются только команда и пользователь `default_session`; существующий
аккаунт greeter и автологин `initial_session` сохраняются. Прежний display
manager отключается от автозагрузки, greetd включается для следующей загрузки.
Текущий display manager не останавливается, сеанс не завершается.

После установки перезайдите в **Niri**. Для проверки экрана входа сохраните
работу и перезагрузите компьютер. На экране входа доступны Niri и другие
установленные сеансы, включая Plasma.

## Состав оформления

- Левая панель Noctalia: рабочие столы, центр управления, трей, уведомления,
  сеть, звук, батарея и раскладка. Включены текущие переопределения порядка
  виджетов из `settings.toml`.
- Тёмная палитра Noctalia, Adwaita Sans, скругления, launcher, история буфера
  обмена и встроенная блокировка. Блокировка через 10 минут, выключение экрана
  через 15 минут, блокировка перед сном.
- Редактор отдельных lockscreen-виджетов выключен, как в исходной конфигурации;
  координаты одного конкретного монитора не копируются.
- Niri: отступы, тени, синие акценты окон, скругления, обзор и настройки ввода.
- Alacritty: fish, прозрачность, размытие, Hack и палитра Catppuccin Mocha.
  Оформление и fish действуют при запуске из меню и по Ctrl+Alt+T.
  Для русской раскладки добавлены эквиваленты Ctrl+Shift+C/V (копировать/вставить),
  Ctrl+Shift+F/B (поиск), Ctrl+A…Z и Alt+B/F/D/T/C/U/L/Y для работы с командной строкой.
- Видео по умолчанию открываются в VLC, изображения — в Loupe. Ассоциации
  остальных типов файлов сохраняются; изменения входят в резервную копию и откат.
  Системная оболочка пользователя и личные пути стандартных папок не меняются.
- Dolphin: схема Noctalia с тёмно-синим фоном, жёлтым выделением, сиреневыми
  ссылками и мятными акцентами из встроенной палитры оболочки. Устанавливается
  в `$XDG_DATA_HOME/color-schemes/Noctalia.colors` и выбирается в `dolphinrc`;
  остальные настройки Dolphin сохраняются. Схема и настройки входят в откат.
  Уже открытый Dolphin нужно закрыть и открыть снова.
- GTK 2/3/4: Lavanda-Sea, тёмный вариант, Noto Sans, значки/курсор Breeze.
  Тема устанавливается в `$XDG_DATA_HOME/themes/Lavanda-Sea`. Текущие
  пользовательские CSS-цвета GTK 3/4 тоже включены в комплект.
- Городской фон для рабочего стола и входа: скачивается с исходного адреса,
  SHA256 проверяется до применения.
- Noctalia Greeter: родная карточка пароля, палитра, часы/дата, выбор сеанса,
  US/RU и масштаб 1.25. Имя пользователя определяется при установке.

Настройки Plasma первого оформления, личные приложения, clipboard,
история, пароли и ключи в комплект не входят. Telegram (Flatpak), Chrome
и Obsidian открываются по горячим клавишам, если уже установлены.

| Сочетание | Действие |
| --- | --- |
| Meta+K / Alt+Space | Launcher |
| Meta+Shift+K | Центр управления |
| Meta+I | Настройки Noctalia |
| Meta+L | Блокировка |
| Meta+Space | Следующая раскладка |
| Ctrl+Alt+T | Alacritty |
| Meta+E | Dolphin |
| Meta+D | Пустой рабочий стол / возврат |
| Win (нажать и отпустить) / Meta+G | Обзор окон |
| Win+вертикальная прокрутка | Предыдущий / следующий рабочий стол |
| Win+горизонтальная прокрутка / Win+←/→ | Колонки окон; на краю — соседний монитор |
| Meta+T / Meta+B / Meta+O | Telegram / Chrome / Obsidian |
| Print / Alt+Print / Ctrl+Print | Область / окно / весь экран |

Полный список: `niri/keybinds.kdl`.

Горизонтальная прокрутка мыши и тачпада работает без искусственной задержки;
для вертикального переключения столов оставлен интервал 150 мс.
В Niri отключён обработчик `meta-wheel-desktops.service` от оформления Plasma,
чтобы он не перехватывал колесо. В Plasma он продолжает работать.

Для одиночного Win в Niri 26.04 используется `niri-super-tap.service` и
`niri/super-tap.py`. Обработчик читает события ввода, не захватывая устройства;
сочетания клавиш, клики и прокрутка отменяют открытие обзора при отпускании Win.
Нужны `python3-evdev` и доступ к `/dev/input/event*` клавиатуры и мыши.
На исходном компьютере этот доступ уже настроен; на другой системе без него
используйте Meta+G или отдельно настройте права устройств ввода.

Файловые диалоги направлены в `xdg-desktop-portal-gtk` через пользовательский
`xdg-desktop-portal/niri-portals.conf`: установленный Dolphin не заменяет Nautilus,
который требуется файловому диалогу GNOME. Остальные порталы сохраняют
приоритет GNOME/GTK, в том числе для демонстрации экрана.

## Параметры

```bash
# План без файлов, скачивания и авторизации
bash ./install-noctalia.sh --dry-run

# Рабочий стол без замены экрана входа
bash ./install-noctalia.sh --desktop-only

# Зависимости уже установлены
bash ./install-noctalia.sh --skip-packages

# Свои обои и масштаб экрана входа
bash ./install-noctalia.sh --wallpaper ~/Pictures/background.png --scale 1.5

# Другая система с заранее установленными зависимостями
bash ./install-noctalia.sh --desktop-only --skip-packages
```

Последний режим не проверен на других дистрибутивах и требует совместимого
синтаксиса Niri/Noctalia. Снимок создан на Niri 26.04, Noctalia 5.4.0;
Greeter проверялся с версией 1.7.0. При `--skip-packages` для полного режима
также нужны greetd, Noctalia Greeter и все его компоненты.

Пути учитывают `XDG_CONFIG_HOME`, `XDG_STATE_HOME` и `XDG_DATA_HOME`. Шаблоны не содержат
фиксированного домашнего каталога. В `~/.local/bin` устанавливаются помощники
`niri-show-desktop` и `niri-open-obsidian`. `noctalia.service` привязан к
`niri.service` и запускается при следующем входе. Установщик не перезапускает
текущую Noctalia. Масштаб Greeter можно изменить через `--scale`.

## Откат

Каждая установка создаёт пользовательскую копию в
`$XDG_STATE_HOME/rodip-noctalia/backups/` (обычно `~/.local/state/…`).
Системные файлы и выбранный display manager сохраняются отдельно в
`/var/backups/rodip-noctalia/`. Пути печатаются при установке.
При ошибке применения пользовательские файлы восстанавливаются автоматически;
системный шаг при своей ошибке тоже пытается вернуть прежнее оформление.

Выйдите из Niri в TTY (Ctrl+Alt+F3) и выполните:

```bash
bash ./install-noctalia.sh --restore
# Или выберите копию:
bash ./install-noctalia.sh --restore ~/.local/state/rodip-noctalia/backups/ИМЯ
```

Полный откат требует системной авторизации. Он возвращает файлы и прежний
экран входа для следующей загрузки. RPM и импортированный ключ RPM не удаляются;
созданные каталоги могут остаться пустыми. Откат первого установщика Plasma
не предназначен для этого оформления.

Для аварийного восстановления только системной части используйте напечатанный
путь системной копии:

```bash
sudo python3 scripts/install-noctalia.py --system-restore /var/backups/rodip-noctalia/ИМЯ
```

## Проверки

```bash
python3 -m unittest discover -s tests -v
bash -n install.sh install-noctalia.sh bootstrap.sh
bash ./install-noctalia.sh --dry-run
```

Тесты проверяют перенос путей, копирование/восстановление, ограничения путей,
сохранение посторонних настроек greetd и ошибки применения. Отрисовка Greeter
проверена на исходном компьютере; тесты не доказывают успешную загрузку
и аутентификацию на другом компьютере.
