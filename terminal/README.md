# Wallpaper accent and glass terminal

Применение из активной KDE-сессии обычным пользователем:

```bash
python3 rodip-glass/scripts/finish-style.py --apply
```

Оригинальная декорация Bart не изменяется. Создаются отдельные Aurorae-копии
Bart-Wallpaper-A/B с цветом рамки из текущего KDE AccentColor. Наблюдатель
QFileSystemWatcher отслеживает изменения конфигурации без опроса shell-командами;
автозапуск включён для последующих сеансов. Переключение копий сбрасывает SVG-кэш
при смене акцента. Авторство и лицензия Bart сохранены в метаданных копий.
Это оформление применяется к серверным рамкам KWin. Приложения с собственными
рамками могут использовать свои настройки.

Konsole: профиль Rodip Glass по умолчанию, fish, непрозрачность фона 76%, нативное
размытие KWin, отступы 14 px, системный моноширинный шрифт и история 10000 строк.
Fastfetch запускается через fish_greeting только в интерактивных Konsole-сессиях.
Системная login-shell и существующий config.fish не изменяются.

Открыть:

```bash
konsole --profile RodipGlass --hide-menubar
```

Резервная копия первого применения: ~/.local/state/rodip-style.
Откат возвращает сохранённые kwinrc/konsolerc и прежние одноимённые файлы,
останавливает синхронизацию акцента и удаляет созданные декорации:

```bash
python3 rodip-glass/scripts/finish-style.py --restore
```

Сохранённый kwinrc возвращается целиком: откат также вернёт его настройки,
сделанные после применения. Запущенные терминалы не закрываются; профиль
по умолчанию используется новыми окнами.
