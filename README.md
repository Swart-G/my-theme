# Rodip Glass

Матовое стеклянное оформление KDE Plasma 6: плавающая верхняя панель,
компактные рабочие столы слева, часы по центру, выезжающий dashboard,
Control Station и экран входа SDDM в одном стиле.

## Быстрая установка

Запускайте из активного сеанса KDE обычным пользователем, без `sudo`:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Swart-G/my-theme/main/bootstrap.sh)
```

Команда скачивает **весь комплект из этого репозитория** и запускает полную
установку. Нужны Bash, curl, tar и Python 3. Исходники сохраняются в
`~/.local/share/rodip-glass/source.*` (или `$XDG_DATA_HOME/rodip-glass/source.*`);
путь к ним выводится перед установкой. Повторный запуск создаёт новую резервную
копию и повторно применяет оформление.

Если репозиторий уже скачан:

```bash
bash ./install.sh
```

Одна команда применяет панель, desktop theme, палитру с акцентом от обоев,
эффект размытия, Control Station и экран входа. В Fedora отсутствующие
зависимости устанавливаются автоматически. Для пакетов и SDDM появится
системная авторизация администратора; весь установщик запускать с sudo не нужно.

Проверить план без изменений:

```bash
bash ./install.sh --dry-run
```

Применить только рабочий стол, без системного экрана входа:

```bash
bash ./install.sh --desktop-only
```

## Что получится

- На каждом подключённом мониторе — одна верхняя панель высотой 48 px.
- Небольшие кнопки рабочих столов слева показывают текущий стол и переключают его.
- Панель плавает с отступами, когда нет развёрнутого окна; при развёрнутом окне
  прилегает к верхнему краю и затемняется. В настоящем полноэкранном режиме
  скрывается автоматически и доступна у края экрана.
- Dashboard появляется только при наведении на центральные часы, с задержкой
  280 ms. При переходе курсора внутрь остаётся открытым.
- В dashboard — часы, рабочие столы с приложениями, медиаплеер и живые CPU/GPU,
  память, диски и сеть. Датчики обновляются, пока dashboard открыт.
- Значки приложений и кнопка KDE скрыты. `Meta+K` открывает меню приложений,
  `Meta+Shift+K` — Control Station.
- SDDM использует текущие обои главного монитора; если их не удалось найти,
  использует включённый нейтральный фон. Экран входа применяется при следующем
  запуске SDDM. Текущий пользовательский сеанс не завершается.

Установка заменяет существующие панели после проверки новых. Виджеты,
размещённые пользователем на рабочем столе, остаются. Настройки автологина,
аутентификации и сеансов SDDM не меняются. Шрифты и темы значков пользователя
не заменяются. Flex Hub не устанавливается.

## Совместимость

Проверено на Fedora 44, Plasma 6.7.5, Qt 6.11.2, Wayland и двух мониторах.
Требуется Plasma 6.7+ в ветке 6.x и пользовательская служба
`plasma-plasmashell.service`. На других дистрибутивах зависимости следует
установить средствами дистрибутива; автоматическая установка пакетов пока
поддерживает Fedora. Чистая установка на других дистрибутивах не проверена.

Основные зависимости: Python 3 + PySide6, Qt 6 qdbus, Plasma Workspace/Desktop,
plasma-nm, plasma-pa, kdeplasma-addons, libksysguard/ksystemstats, KDE Connect,
Qt Quick и Qt5Compat. Для экрана входа — SDDM с greeter Qt 6.

## Резервные копии и откат

Перед изменениями создаётся частная резервная копия в
`~/.local/state/rodip-glass/backups/`; путь печатается при установке.
Каждая установка сохраняет отдельную копию, включая предыдущие пакеты и
конфигурацию. Системная копия темы SDDM хранится в
`/var/lib/sddm/rodip-glass-backups/`.

Для точного отката выйдите из KDE, войдите в TTY (Ctrl+Alt+F3) и выполните:

```bash
bash ./install.sh --restore
```

Откатывается последняя установка. Чтобы выбрать другую копию:

```bash
bash ./install.sh --restore ~/.local/state/rodip-glass/backups/ИМЯ_КОПИИ
```

Установленные пакеты Fedora при откате не удаляются. При ошибке установки
установщик сохраняет резервную копию и причину сбоя; автоматического полного
отката нет. Прежние панели удаляются только после проверки новых.

## Что входит в репозиторий

Все компоненты конечного оформления включены в исходниках:

| Компонент | Путь | Что настраивает |
| --- | --- | --- |
| Glass Panel | `theme/` | Матовое стекло панели и стандартных всплывающих окон |
| Верхняя панель и dashboard | `plasmoids/local.bart.modularpanel/` | Выравнивание, центральные часы, выезжающее меню при наведении только на центр, часы и дата в меню, рабочие столы и приложения, музыка и датчики |
| Переключатель рабочих столов | `plasmoids/local.bart.desktopnumbers/` | Компактные номера слева и выделение активного стола |
| Системный монитор | `plasmoids/local.bart.systemmonitor/` | CPU, GPU, память, накопители и сеть; сведения о процессоре определяются на вашем компьютере |
| KDE Control Station | `plasmoids/KdeControlStation/` | Центр управления вместо Flex Hub, стеклянный вид и сочетание `Meta+Shift+K` |
| Поведение окон и панели | `kwin/` | Плавающие отступы, затемнение над развёрнутым окном и скрытие в полноэкранном режиме на каждом мониторе |
| Раскладка и восстановление | `plasma/`, `scripts/` | Панели на мониторах, скрытые значки приложений и KDE, меню по `Meta+K`, восстановление при входе и изменении подключённых мониторов |
| Цвета | `colors/` | Общая палитра, акцент от текущих обоев и размытие KWin |
| Экран входа | `sddm/` | Стеклянная форма входа, часы и дата, выбор пользователя и сеанса, текущие обои главного монитора |

Большие часы, медиаплеер и мониторинг находятся в выезжающем меню и не занимают
рабочий стол постоянно. Flex Hub, Menu 11 Enhanced и оформление macOS не входят
в конечный набор. Личные обои и настройки учётной записи не публикуются: фон
экрана входа берётся из текущего оформления компьютера при установке. Акцент
следует за обоями средствами Plasma; остальные цвета используют палитру Rodip Glass.

Исходники: [Swart-G/my-theme](https://github.com/Swart-G/my-theme).

## Проверка пакета

```bash
python3 -m unittest discover -s tests -v
bash -n install.sh
```

Тесты проверяют резервное копирование/восстановление, ограничения путей,
установку и откат SDDM в изолированных временных каталогах и переносимость
комплекта. Они не проверяют реальный вход по паролю. На текущей системе
отдельно проверены применение панели и работа формы входа в предпросмотре.

## Последние настройки

Колёсико над рабочими столами: вверх — предыдущий стол, вниз — следующий;
на крайних столах переключение останавливается.
`Win` (`Meta`) + колёсико переключает рабочие столы из любого приложения:
вверх — предыдущий, вниз — следующий, как над цифрами. Это служба `meta-wheel-desktops`,
которая использовалась на исходном ПК. Она запускается вместе с графической
сессией, перехватывает вертикальную прокрутку при зажатом Win и передаёт остальные
события мыши. Переключение выполняется штатными действиями KWin, включая его
настройку перехода между крайними столами.

Установщик добавляет Python evdev (пакет `python3-evdev` в Fedora) и системные
правила udev для доступа активного локального пользователя к клавиатуре, мыши
и `/dev/uinput`. Для этого нужен запрос администратора также с `--desktop-only`.
Правила и пользовательская служба сохраняются для отката. На других
дистрибутивах заранее установите Python evdev, udev и утилиту modprobe.
Если мышь с колёсиком недоступна или настройка службы завершилась ошибкой,
установщик выводит предупреждение и продолжает настройку оформления, включая
перезапуск Plasma для применения экрана блокировки. Причина сохраняется в
`meta_wheel.error` файла `~/.local/state/rodip-glass/report.json`.
Для повторной настройки подключите мышь и снова запустите установщик.
Установщик также создаёт декорацию рамок с акцентом обоев и стеклянный профиль
Konsole (fish + fastfetch, прозрачность 24%, размытие). Оригинальная Bart
не изменяется. Подробности и отдельный откат: [terminal/README.md](terminal/README.md).

## Экран после сна и исправление qdbus

Экран блокировки Plasma настраивается отдельно от SDDM. Установщик создаёт
пакет Plasma/Shell `org.rodip.glass.shell` с резервным пакетом штатного рабочего
стола: он добавляет только стеклянную карточку к установленному экрану блокировки
Plasma 6.7 и сохраняет его код авторизации. Обои берутся с основного рабочего стола.
Карточка отображается вокруг формы ввода пароля после движения мыши или нажатия
клавиши. Часы и дата остаются без фона. При каждой установке пакет собирается
заново из штатных файлов KDE, поэтому ранее добавленный фон часов удаляется.
Настройки включены в общий откат; глобальная тема Bart не заменяется.

Все вызовы нового модуля оформления находят Qt6 qdbus по полному пути Fedora
(`/usr/lib64/qt6/bin/qdbus`), затем проверяют qdbus6/qdbus в PATH.
После обновления повторите обычную команду установки из начала README.

Механизм пакета и резервного рабочего стола проверен по исходникам KDE:
[ShellPackage](https://github.com/KDE/libplasma/blob/Plasma/6.7/src/plasma/packagestructure/shell/shellpackage.cpp),
[ShellIntegration](https://github.com/KDE/kscreenlocker/blob/Plasma/6.7/settings/shell_integration.cpp).

## Глобальная тема KDE

После установки **Rodip Glass** доступна в «Параметры системы → Цвета и темы →
Глобальная тема». Она также назначается вариантом тёмной темы в быстрых настройках.
Bart и Lavanda остаются отдельными установленными темами. Обои, шрифты и значки
не входят в defaults нового пакета и не заменяются при его выборе.

Обычная установка без дополнительных флагов настраивает **оба** экрана:
SDDM при входе в систему и штатный KScreenLocker после сна/блокировки.
`--desktop-only` явно пропускает SDDM; отчёт теперь содержит отдельные результаты
`screens.login` и `screens.lockscreen`. Для системного этапа нужно подтвердить
стандартный запрос администратора. Активная графическая сессия не завершается;
новая тема SDDM появится при следующем запуске экрана входа.

Оба экрана настраиваются до создания и проверки панелей: ошибка панели больше
не пропускает установку SDDM. Установщик учитывает приоритет `/etc/sddm.conf`,
сохраняет его копию и меняет только `Current` и `ThemeDir` в секции `[Theme]`.
Откат возвращает исходный файл. При ошибке системного этапа отчёт содержит её
причину и результат установки экрана блокировки.

Палитра интерактивного fish включает светлые автоподсказки, комментарии и меню
дополнений. После установки откройте новый терминал или выполните в fish:

```fish
source "$__fish_config_dir/conf.d/rodip-glass.fish"
```
