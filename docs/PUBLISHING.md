# Репозиторий и выпуски

Основной репозиторий: https://github.com/Swart-G/my-theme, ветка `main`.
Команда в README получает текущую версию `bootstrap.sh`; тот скачивает весь
архив ветки и запускает полный установщик. Для фиксированных выпусков можно
добавлять теги и заменять ссылку на архив в bootstrap на конкретный тег.

Перед обновлением запускайте тесты и `install.sh --dry-run`. В репозиторий
не следует добавлять личные обои, домашние настройки и резервные копии.
